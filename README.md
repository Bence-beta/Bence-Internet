# 🌐 Bence Internet

Üdvözlünk a **Bence Internet** hivatalos GitHub oldalán! 

A Bence Internet egy saját fejlesztésű, modern és gyors webböngésző, amely az **NW.js** (Chromium motor) segítségével készült. A projekt célja egy olyan könnyen használható, testreszabható böngésző létrehozása volt, amely a megszokott funkciók mellett saját egyedi dizájnt kínál.

*(Ha a haladóbb, extra funkciókkal rendelkező verziót keresed, nézd meg a **Bence Internet Pro** repository-t is!)*

---

## ✨ Főbb funkciók

- **Modern, Chrome-szerű felület:** Letisztult fülsáv, okos címsor és könyvjelző sáv.
- **Több fül kezelése:** Új fülek nyitása (Ctrl + T), fülek közötti váltás és zárás (Ctrl + W).
- **Beépített kezdőlap:** Saját kezdőlap elegáns keresőmezővel és gyorslinkekkel (YouTube, GitHub, Google).
- **Gyorsgombok:** F5 (újratöltés), Ctrl + L (címsor fókuszálása), Alt + Bal/Jobb (előre/hátra).
- **Keresés az oldalon:** Ctrl + F segítségével azonnal kereshetsz a megnyitott weboldalakon.

---

## 🚀 Telepítés és futtatás

### Legegyszerűbb mód (Windows)
1. Lépj a jobb oldali **Releases** (Kiadások) fülre.
2. Töltsd le a `BenceInternet.exe` fájlt.
3. Kattints duplán a letöltött fájlra, és már indul is a böngésző!

### Futtatás forráskódból (Fejlesztőknek)
1. Töltsd le az [NW.js](https://nwjs.io/) SDK verzióját.
2. Klónozd ezt a repository-t, vagy töltsd le a fájlokat.
3. Csomagold ki az NW.js-t, és másold a mellé a projekt fájljait (`index.html`, `home.html`, `package.json`, `icon.png`).
4. Indítsd el az `nw.exe`-t.
